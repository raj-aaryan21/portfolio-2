AARYAN RAJPAL HTML PORTFOLIO

Files:
- index.html
- style.css
- script.js
- assets/profile.png
- assets/education-*.png

How to use:
1. Put the whole 'aaryan_portfolio_html' folder inside your XAMPP htdocs folder.
2. Start Apache in XAMPP.
3. Open: http://localhost/aaryan_portfolio_html/
4. Put your own resume.pdf in the main folder so the Download Resume button works.
5. The profile image and education background images are crops from the screenshots you supplied. Replace them with your original images for best quality.

Note:
The contact form is front-end only. It does not send email until connected to a backend/email service.
